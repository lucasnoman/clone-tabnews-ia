# Sobre o projeto

Este projeto é uma aplicação web simples construída com Next.js e App Router. A página inicial exibe os nomes LUCAS, IRIA e HANA, centralizados e em letras maiúsculas.

## Estrutura e execução

- `app/page.js` define a página inicial.
- `app/layout.js` define o layout raiz e os metadados.
- `app/globals.css` contém os estilos globais.
- Use Node.js 20.9 ou superior.
- `npm run dev` inicia o servidor de desenvolvimento; `npm run build` cria a versão de produção e `npm start` a executa.

Ao alterar o projeto, preserve sua simplicidade e use as convenções do App Router.
